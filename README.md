### 🖥️ The Home Lab

Software isn't just something I write — it's something I run. My setup:

```
MacBook (Neo) ── daily driver, where Claude Code and dev work happen
     │
     ├── skywalker  (Orange Pi 5 Plus, garage) ── monitoring stack + Minecraft servers
     └── underworld (garage board)              ── fixed-IP house server
```

Passwordless SSH between all three, a shared family NAS over SMB, and a network printer everyone can hit — the kind of infrastructure most people don't set up until their first real job, except I did it for a Minecraft server.
